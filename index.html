web_tools

Small tools for everyday engineering work. Each one is a single page with no dependencies and no build step. Your files never leave the browser.

  • favicon_generator

    Turn one PNG or SVG into the full set of icon files browsers and devices expect, packed as a zip.
  • JS_Scratchpad

    Write JavaScript and run it in a sandboxed frame, with console output beside the editor.
  • JSON_beautifier

    Format, collapse and inspect JSON, with errors pointed at the line that caused them.
  • Printer_Test

    Read live status from an ESC/POS receipt printer over WebUSB, and send a test cut.
  • SVG_resizer

    Drop in an SVG, set the size you want, and take it back out as SVG or PNG.
  • text_bench

    Stack text transforms one after another: case, spacing, line order, encoding.

Open source on GitHub.
