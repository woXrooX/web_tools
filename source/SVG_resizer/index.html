A resize changes the width and height the SVG asks for on screen. The drawing itself keeps its coordinates, and the viewBox maps them onto the new box — so the result stays sharp at any size. Turn on “Rewrite coordinates” when another tool needs the viewBox itself to match, such as 0 0 24 24 for an icon set.
