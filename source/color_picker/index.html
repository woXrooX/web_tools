Color picker

Edit a color in any CSS format and every other format follows. Each field accepts any format, including named colors, so you can paste whatever you have into any of them. The URL keeps the current color, so you can share it.

rgb and hsl syntax

    The color is kept at full precision and fields are rounded only for display, so editing one field never makes the others drift. hex is 8 bits per channel. lab and lch use the D50 white point, as CSS does. When a color is outside sRGB, hex, rgb, hsl and hwb show the nearest sRGB color using the CSS Color 4 gamut mapping, and the sliders work on that color. Contrast follows WCAG 2 and is rounded down.
